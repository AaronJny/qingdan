青单 · Apple Silicon · macOS 13 及以上

安装
1. 正常退出旧版。如果“应用程序”内仍有旧名 Qingdan.app，先移走旧应用；保留 Library/Application Support/QingdanDesktop 数据目录。
2. 将镜像中的“青单.app”拖到 Applications，再从“应用程序”打开。
3. 打开即进入本机工作台，无需安装 Node.js、运行命令或设置账号密码。

连接私服
打开“文件 → 服务器连接”，填写自己的青单 HTTPS 私服地址，再使用服务器账号登录。本机数据与私服数据分别保存，不会自动合并。

备份与升级
使用“退出青单”正常退出后，完整复制 ~/Library/Application Support/QingdanDesktop。升级时替换应用，保留数据目录。

此版本尚无 Developer ID 签名或 Apple 公证，系统可能阻止运行。遇到安全警告时，请先核实下载来源，保留系统安全设置。
