青单 1.1.1 · Windows x64

1. 把这个ZIP完整解压到一个目录，双击Qingdan.exe。所有文件需要保留在一起。
2. 默认自动启动内置本机服务，直接使用单人清单，无需安装Node、运行命令或设置账号密码。
3. 如需连接自己的多设备私服，在菜单“连接设置”中选择连接私服，填写准确HTTPS地址。账号由你自己的服务器管理。
4. 正常退出应用后再备份数据。数据保存在%APPDATA%\QingdanDesktop；替换程序目录升级不会主动删除该目录。

此版本使用Electron内置Node24和SQLite，服务只监听127.0.0.1。程序不包含用户数据、预设账号或密码。
成品ASAR、依赖文件与安全fuses校验以本次构建报告为准。普通Node后端检查不代表Windows原生GUI启动已通过；当前没有本项目发布者数字签名。请勿关闭系统安全设置来运行软件。
