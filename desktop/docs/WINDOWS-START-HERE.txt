青单 · Windows x64

安装
完整解压 ZIP 后，双击 Qingdan.exe。所有文件应保留在同一目录。
打开即进入本机工作台，无需安装 Node.js、运行命令或设置账号密码。

连接私服
打开“文件 → 服务器连接”，填写自己的青单 HTTPS 私服地址，再使用服务器账号登录。本机数据与私服数据分别保存，不会自动合并。

备份与升级
正常退出应用后，完整复制 %APPDATA%\QingdanDesktop。升级时替换程序文件，保留数据目录。

此版本尚无发布者数字签名，系统可能阻止运行。遇到安全警告时，请先核实下载来源，保留系统安全设置。

未保存的内容
编辑时若保存失败，请先选择“导出未保存的输入”，确认文件已保存，再重新打开应用。普通任务备份不包含这些未保存内容。
