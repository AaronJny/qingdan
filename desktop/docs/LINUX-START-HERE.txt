青单 · Linux x64

安装
下载 Qingdan-版本-linux-x64.AppImage，在文件属性中允许作为程序执行，再打开。也可以运行：
chmod +x ./Qingdan-版本-linux-x64.AppImage

需要 x86-64 Linux 图形桌面，并能正常启用 Electron 沙箱。

不支持 FUSE 时，可在空目录中执行：
./Qingdan-版本-linux-x64.AppImage --appimage-extract
./squashfs-root/AppRun
保留整个 squashfs-root 目录。

使用与私服
打开即进入本机工作台，无需安装 Node.js。通过“文件 → 服务器连接”可连接自己的 HTTPS 私服；本机数据不会自动上传或合并。

备份与升级
正常退出应用后，完整复制 ${XDG_CONFIG_HOME:-~/.config}/QingdanDesktop。升级时替换 AppImage，保留数据目录。

如果系统无法启用 Electron 沙箱，请使用兼容的系统环境，保留系统安全设置。
