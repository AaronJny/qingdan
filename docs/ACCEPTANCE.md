# 验收范围

## 连接与数据边界

- 本机免登录、私服账号登录、切换和返回本机均可完成。
- 切换必须显式确认，本机数据、私服会话和不同服务器的数据互相隔离。
- 取消、加载超时、服务异常、重复点击和旧请求迟到不得造成假成功或配置混用。
- 页面不得通过桥接接口读取文件或直接修改服务器地址。

## 桌面持续运行与快捷录入

- 关闭窗口、托盘恢复、明确退出、睡眠唤醒和连续异常的行为有明确区别。
- 断网时保留当前工作台和输入；恢复连接不重载覆盖编辑内容。
- 全局快捷键失败有反馈；新增任务仍使用当前服务与当前账号的正式保存链路。
- 切换或退出后取消旧服务的调度、请求和待触发通知。

## 离线与恢复

- 已支持的断网操作持久保留，重启后可核对；未支持的操作明确要求在线。
- 固定操作标识保证超时重试不重复创建，冲突保留原输入，不自动覆盖新版。
- 每个服务器、账号的队列独立；未登录、账号拒绝或切换后不可将旧队列发给新账号。
- 最近同步时间只在完整数据实际提交后更新。

## 外部日历与调休

- 外部订阅清楚标明来源，只读且无向外部日历写入的入口。
- 抓取限制协议、目标、重定向、响应大小和超时，并防止内部网络探测。
- 调休开关默认关闭并持久保存，关闭后停止该账号调度、后台抓取和日期标记；其他主动开启用户可共用缓存。
- 调休更新由服务端统一缓存；每实例每日最多一个自动批次，单并发错峰。
- 手动更新有冷却，429 遵守 Retry-After，403 停止自动更新，不通过替换路线绕过。
- 节流跨账号并发共享且重启后保留；源站不可用时保留缓存并显示更新时间。
- 缺少法定安排的年份显示未知，不把普通周末估计作为官方调休数据。

## 分发

- 所有平台产物来自同一最终源码快照；安装包、源码和说明版本一致。
- 保留既有应用身份、用户目录、数据迁移约束及 Mac 辅助程序结构。
- 将自动测试、结构检查、浏览器测试和平台原生运行分别记录，不互相替代。
