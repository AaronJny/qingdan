## 复现

1. 使用 Node.js 24，在 `application/` 执行 `npm ci` 和 `npm run build`。
2. 将 `QINGDAN_DATA_DIR` 指向专门用于截图的全新空目录，保持默认本机模式和回环监听，执行 `npm start`。不要使用真实个人数据目录。
3. 打开本机页面，点击空任务页的“添加一组明确标注的示例”。示例日期随运行当天变化。
4. 分别打开“所有任务”“日历”“四象限”“习惯”。习惯图中对“示例：每天阅读”执行了一次“完成目标”。
5. 在浏览器直接截图。更新图片时同时记录源码提交与采集日期，确认不包含真实账号、任务、服务器地址、文件或其他私人资料。

合成数据目录和运行时只用于采集，不提交到仓库。
