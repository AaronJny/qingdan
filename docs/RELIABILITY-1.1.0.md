# 青单 1.1.0 可靠性修复与验证

## 本次修复

- 跨账号移动任务及子任务时，在同一事务内更新附件所有者；附件元数据按当前任务访问权限返回，原文件字节与对象键保持完整。
- v1 备份恢复重新关联专注记录与恢复后的习惯；缺失或类型错误的习惯引用清空并提示，重试保持幂等。
- 独立服务构建补齐隔离日历解析 worker；运行依赖分析覆盖全部服务入口。
- 运行版本、锁文件与完整检查证据以 1.1.0 为准。源码和全部编译文件均记录精确哈希；变化后的源码、额外迁移或被修改的输出不能作为已验证输入打包。
- 桌面后端从当前完整检查通过的源码生成，包含迁移、在线/离线页面及锁定依赖；拒绝覆盖源码、用户数据或无关目录。
- 服务端发行流程使用既有运行时准备与组装流程，校验官方 Node 归档、二进制及许可证，并独立解压最终 ZIP 验收。
- 修复跨平台路径、Windows 测试关闭方式、嵌套依赖清单和过期设置测试；添加分支 push 检查及 Windows/macOS 普通 Node 后端检查。

## 验证边界

普通 Node 后端测试不代表 Electron utilityProcess 或桌面 GUI 的实机验收。当前本地验证没有完成 Windows/macOS 安装包原生启动、macOS 挂载/拖拽、公证、Android APK、Docker、真实 HTTPS 私服或外部部署验证。GitHub Actions 的跨平台结果以对应提交的检查记录为准。

手工运行发布工作流仅构建和验收；只有匹配版本的标签 push 才进入发布阶段。本次源码更新不创建 Release 或部署。

源码重建步骤见 [桌面构建](../desktop/docs/BUILD-RELEASE.md) 和 [服务端构建](../server-packaging/BUILD.md)。
